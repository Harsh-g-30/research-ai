# 🔍 ResearchAI

> AI-powered product research platform that turns a single query into ranked, explainable recommendations — in under 2 minutes.

---

## 📌 The Problem

Researching a product today looks like this:

Google → 10 tabs → YouTube → Reddit → ChatGPT → still confused

**ResearchAI** replaces that entire workflow with one guided experience: describe what you want, get dynamic filters, let the AI research for you, compare top picks side by side.

---

## ✨ Features

- 🧠 **Conversational input** — describe your need in plain language
- ⚡ **LangGraph multi-agent pipeline** — autonomous web research, extraction, ranking
- 🎛️ **Dynamic filter generation** — category-aware filters auto-generated by LLM (RAM/GPU for laptops, engine/torque for cars, etc.)
- 📊 **Side-by-side comparison** — compare 2–3 products with AI-written tradeoff analysis
- 💬 **Explainable recommendations** — every result tells you *why* it matches your needs
- 🔄 **Real-time streaming** — results stream live via WebSockets as the agent researches
- 💾 **Search history** — save and revisit past research sessions

---

## 🏗️ Architecture

```
User Query
    │
    ▼
[ Intent Extraction ]        ← Gemma 2 9B (Groq) — fast, structured JSON
    │
    ▼
[ Dynamic Filter Generation ]← LLM infers category-specific filter schema
    │
    ▼
[ LangGraph Research Agent ]
    ├── Node 1: Generate search queries
    ├── Node 2: Web search (Tavily API)
    ├── Node 3: Extract product data
    ├── Node 4: Embed → ChromaDB (RAG)
    └── Node 5: Rank + Explain
    │
    ▼
[ FastAPI Backend ]          ← REST + WebSocket
    ├── PostgreSQL            ← users, sessions, history
    ├── Redis                 ← cache (sub-200ms on repeat queries)
    └── Celery Workers        ← async long-running research tasks
    │
    ▼
[ Next.js Frontend ]         ← dynamic filters UI, streaming results, compare view
```

## 🚀 Getting Started

### Prerequisites

- Python 3.11+
- Node.js 20+
- Docker Desktop

### 1. Clone the repo

```bash
git clone https://github.com/yourusername/research-ai.git
cd research-ai
```

### 2. Set up environment variables

```bash
cp .env.example .env
```

Fill in your API keys in `.env`:

```env
GROQ_API_KEY=your_key_here
TAVILY_API_KEY=your_key_here
GEMINI_API_KEY=your_key_here
DATABASE_URL=postgresql://postgres:postgres@localhost:5432/researchai
REDIS_URL=redis://localhost:6379
SECRET_KEY=your_secret_key_here
```

### 3. Start PostgreSQL + Redis

```bash
docker-compose up -d
```

### 4. Run the backend

```bash
cd backend
python -m venv venv
venv\Scripts\activate        # Windows
source venv/bin/activate     # Mac/Linux

pip install -r requirements.txt
uvicorn app.main:app --reload
```

Backend runs at → `http://localhost:8000`
API docs at → `http://localhost:8000/docs`

### 5. Run the frontend

```bash
cd frontend
npm install
npm run dev
```

Frontend runs at → `http://localhost:3000`
